## douyindl：支持抖音图文笔记（/note/<id>）链接

- 问题：短链 `https://v.douyin.com/t9hurITjT14/` 跳转后是 `https://www.douyin.com/note/7665298966041012475`，
  `resolve_share_url` 解析不到资源类型报错「无法从链接解析资源类型」。
- 修复（`src/douyindl/downloader.py`，最终版）：
  1. 新增 `_NOTE_ID_PATTERN = re.compile(r"/note/(\d+)")`，在 `_try_resolve` 中命中返回 `("one", id)`；
     note 的 id 即 aweme_id，按单资源走 `fetch_one_video` 即可。
  2. `fetch_one_video` 处理图文笔记：`aweme_detail.video.bit_rate` 为空 → 视为图文笔记，
     从 `aweme_detail.images[].url_list[0]` 提取图片地址写入 `item["images"]`、`item["is_image_note"]=True`，
     **并清空 `video_play_addr`**（关键：图文笔记的 `video.play_addr` 实为 `audio/mp4` 音频，不是视频，
     第一次实现误下成音频 mp4，已纠正）。
  3. `Downloader.run()` 下载循环中：`not play_addr and images` 时调用 `_download_image_note`，
     把图片下载到 `YYYYMMDD_文案_awemeid/` 子目录（`01.webp`/`02.webp`…），并写入进度库（file_path 记首图）。
     新增模块级 `_image_ext()` 与类方法 `_download_image_set()` / `_download_image_note()`。
  4. 多链接总结（`run_all`）失败行改为展示**原始短链 + 失败原因**：
     `[i/N] 失败 {原始url} - 失败: {error}`，此前失败行只显示 error 文本、丢失原始链接。
- 验证：
  - 图文笔记下载为真实 WEBP 图片（`file` 确认 1920x1080 VP8），非音频。
  - 解析失败总结行：`[2/2] 失败 https://v.douyin.com/thisisnotreal123 - 失败: 无法从链接解析资源类型: ...`。
- 已知限制：`--retry-failed` 仅重试视频（按 `video_play_addr`），图文笔记失败不会经此路径重新下图片。

## douyindl：已删除/私密视频日志从 NoneType 改为可读原因

- 问题：链接 `v.douyin.com/F3cMFXGXixo/`、`v.douyin.com/AYbQRvZ6GT4/` 是**已被作者删除/私密**的视频，
  多链接总结只显示晦涩的 `'NoneType' object has no attribute 'get'`，看不出真因。
- 根因判定（`downloader.py`）：该 `NoneType` 错误**唯一来源**是 `fetch_one_video` 中 `aweme_detail.get("video")`，
  而 `aweme_detail` 为 `None` 仅发生在接口返回 `{"aweme_detail": null}`（删除/私密/风控空数据）时——
  `response.get("aweme_detail", {})` 因键存在但值为 None 不启用默认 `{}`。其余 `.get` 调用均有 `x.get(k) or {}` 保护。
- 修复：
  1. `fetch_one_video`：`aweme_detail = response.get("aweme_detail")` 后加 `if not aweme_detail: raise ValueError("视频可能已被作者删除或设为私密，接口未返回内容（aweme_detail 为空）")`。
     该 ValueError 不在 `_request_with_retry` 重试清单（APIResponseError/RateLimit/Connection/Timeout）内 → **确定性失败、不白重试**。
  2. 新增模块级 `_humanize_error(e)`：把底层异常翻译为中文可读原因（已删除/网络失败/403/429/其它 NoneType 兜底），
     `run_all` 的异常捕获处用它生成 reason 并写入 `error` 字段，总结与 `下载失败:` 日志均显示可读文案。
- 验证：`v.douyin.com/F3cMFXGXixo/` / `AYbQRvZ6GT4/` 总结显示
  `失败: 视频可能已被作者删除或设为私密，接口未返回内容（aweme_detail 为空）`，且每个链接仅报错一次（无重试浪费）。
