## 新增文档：分享链接机制分析
- 用户提问：同一视频多次分享为何得到不同短链（如 `PFg1MB_kChk` vs `GQP7lTFztb4`），却解析为同一 `aweme_id=7653736004347612450`；底层原理及 `aweme_id` 去重。
- 实证：用 curl 探测两短码，均 302 跳到 `iesdouyin.com/share/video/7653736004347612450/`，差异仅在 `social_share_id`/`social_share_time` 等带不同时间戳的追踪参数（分享归因）。
- 产出：`docs/08-share-link-mechanism.md`，覆盖：① 短链是服务端 KV 映射的「钥匙」非内容本身（随机不透明，每次分享 mint 新码）；② `aweme_id` 是内容唯一稳定主键；③ 重定向追踪参数=分享归因，不影响下载；④ 工具三层去重（解析取 aweme_id / 进度库 PRIMARY KEY / 文件名后缀）；⑤ 视频 CDN 地址带过期签名故重试需重拉。
- 更新文档列表：`CLAUDE.md` §文档索引、`README.md` 文档表、`docs/03-development.md` §下一步 均已加 `08-share-link-mechanism.md` 引用。
