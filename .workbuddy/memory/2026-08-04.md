# 2026-08-04

## 修复：无标题视频文件名碰撞导致误跳过
- 现象：多个仅含话题标签（如 `#比亚迪_#原创作品`）的视频，文案被 `_sanitize_filename` 的话题去除逻辑清空，回退为 `untitled`，单视频文件名均为 `20260804_untitled.mp4`，后续同名被「文件已存在」误跳过。
- 根因：`downloader.py` 单视频/合集路径（原 1114 行）与重试路径（原 982 行）用 `_sanitize_filename(desc) or aweme_id`，但该函数对空文案返回 `"untitled"`（truthy），aweme_id 兜底永远不触发。
- 修复：新增 `_build_video_name(desc, aweme_id, max_len)` 与 `_extract_topics(desc)`：
  - base 优先级：真实文案（去话题后）> 话题文字拼接 > `untitled`；
  - 末尾强制追加 `_<aweme_id>`，杜绝同名碰撞；
  - `_extract_topics` 正则由 `#([^\s#]+)` 改为 `#([^\s#_]+)`，避免把分隔符 `_` 吞进话题名（修复双下划线 `比亚迪__原创作品`）。
  - 替换两处调用（单视频/合集、重试）。
- 验证：`_build_video_name` 单测 5 用例通过；端到端用此前被跳过的链接 `Fg316sETq-Y`（aweme_id 7660098234723954809）实测下载成功，产出 `downloads/20260804_比亚迪_原创作品_7660098234723954809.mp4`，「成功 1/1，跳过 0」。
- 过渡提醒：修复前遗留的 `downloads/20260804_untitled.mp4`（85MB，即首个视频 7643780377336614321）为重复空名文件，建议删除避免重跑时再下载一份。
- 同步更新 CLAUDE.md「关键坑点」新增「文件命名规则（含 aweme_id，防碰撞）」一节。
